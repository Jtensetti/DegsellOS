# Färdplan

## 2027.1

- [x] Signerade systemavbildningar för amd64 och arm64, interaktiv PC-installation och ett UTM-paket.
- [x] Installation på vald disk med en andra datadisk ansluten.
- [x] Upprepning av ett skyddat forskningsprojekt efter systemuppgradering.
- [x] ForskarOS som produktnamn i startmeny, installerare och GNOME:s välkomstguide.
- [x] Jämförelse av tidigare och aktuellt underlag, import av Zotero-markeringar och en projektmall för källtolkning.
- [ ] Inloggning, mappdelning och labbkörning på en fysisk MacBook Neo.
- [ ] Jämförelse med tre forskarprofilers ordinarie arbetsmiljöer, med mätning av tid, handgrepp, fel och hjälpbehov.
- [ ] Fyra veckors användning för att bedöma arbetsmetoden och måtten på självständigt arbete.
- [ ] Kvartalsutgåva 2027.1.

## Senare utveckling

- Krypterad säkerhetskopiering och klientpolicy för verifiering av systemavbildningens signatur.
- Lokala AI-konsultationer via Ollama och självhostad litteratursökning.
- Fristående Markdown-editor med stöd för Core, wikilänkar och bakåtlänkar.
- Nix eller Guix som körmiljö per studie samt direkt uppstart av Linux på kompatibel Apple Silicon-hårdvara.
