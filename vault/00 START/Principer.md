# ForskarOS – våra principer

**Framtiden är den viktigaste tiden.** Vi använder historia och samtid för att öppna nya möjligheter, inte för att försvara gamla antaganden.

| Begrepp | Systemregel | Observerbart beteende |
|---|---|---|
| Kommunikation | Kunskap måste kunna förklaras | Skriv en begriplig forskningssammanfattning |
| Ifrågasättande | Ingen idé är helig | Formulera ett seriöst motargument |
| Möten | Mötet ska ge kunskap | Skriv viktigaste lärdomen och invändningen |
| Vision | Utgå från en viktig fråga | Beskriv långsiktigt värde och konsekvenser |
| Respektlöshet | Utmana auktoriteter, respektera belägg | Granska etablerade antaganden sakligt |
| Mod | Testa idéer som kan visa sig fel | Gör ett prövningsbart påstående offentligt när lämpligt |
| Arbete | Genomför det svåra arbetet | Avsluta ett reproducerbart arbetsprov |
| Kontakter | Sök motstånd utanför AI | Ta kontakt med en relevant expert |
| Lekfullhet | Tillåt oväntade experiment | Generera en ny möjlig kombination |
| Kompetens | Bygg förmåga, inte bara resultat | Lös och förklara en uppgift utan AI |
| Nätverk | Få återkoppling från oberoende människor | Dokumentera ett faktiskt utbyte |
| Kombinera | Korsbefrukta discipliner | Jämför minst tre perspektiv |
| Envishet | Håll fast vid frågan | Fortsätt pröva trots motgångar |
| Mångfald | Sök verkliga perspektivskillnader | Inkludera motstridiga teorier och människor |
| Tillit | Visa grunden för påståenden | Spåra källa, tolkning, osäkerhet och fel |
| Förändring | Ändra dig när beläggen ändras | Skriv en daterad omprövning |
| Friktion | Sträva efter produktiv oenighet | Formulera starkaste invändningen |
| Bekväm med att vara obekväm | Utforska osäkerhet utan prestige | Skriv ned vad du inte förstår |
| Framtiden | Kunskap ska öppna möjligheter | Beskriv vilken framtid en upptäckt gör möjlig |

Det finns ingen poäng med intellektuell friktion utan respekt för människor. Ingen belöning för att bara producera fler dokument.
