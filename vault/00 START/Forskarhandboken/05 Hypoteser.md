# 5. Hypoteser

En hypotes som inte kan visa sig fel säger inget om världen. Hypotesmallen frågar därför efter:

- **Prediktioner:** vad borde observeras om hypotesen stämmer?
- **Falsifiering:** vilken observation skulle tala emot den?
- **Konkurrerande förklaringar:** vad mer kan ge samma observationer?
- **Etablerad kunskap** som hypotesen bygger på, och **vad som är nytt**.

Ett negativt resultat är ett resultat om metoden är sund. Skriv hur säker du är på hypotesen och följ upp i omprövningen.

## Övning utan AI
Skriv hypotesen och den observation som skulle tala tydligast emot den. Om den observationen inte går att göra är hypotesen inte prövbar än.
