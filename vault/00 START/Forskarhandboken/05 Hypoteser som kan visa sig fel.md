# 5. Hypoteser som kan visa sig fel

En hypotes som inte kan visa sig fel säger ingenting om världen. Hypotesmallen kräver därför:

- **Prediktioner:** vad borde du observera om hypotesen stämmer?
- **Falsifiering:** vilken observation skulle tala emot den?
- **Konkurrerande förklaringar:** vad mer skulle kunna ge samma observationer?
- **Etablerad kunskap** som hypotesen vilar på, och **den ovanliga kombinationen** som gör den ny.

**Envis med frågan, inte med svaret.** Om hypotesen faller har du lärt dig något. Ett negativt resultat är ett forskningsresultat när metoden är sund.

**Konfidens.** Skriv hur säker du är (låg, medel, hög) och varför. Följ upp i omprövningen.

## Övning utan AI
Skriv din hypotes. Skriv sedan den observation som skulle göra dig mest besviken. Är den möjlig att göra? Om inte, är hypotesen inte prövbar än.
