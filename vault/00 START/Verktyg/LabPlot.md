# LabPlot

> Diagram och dataanalys

**Fas:** 5 · Utveckla  
**Profil:** Statistik och data

## Hur det tjänar metoden

Utveckla: visualisera data för att se mönster, och det som talar emot dem.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Statistik och data**, eller kör:

```bash
forskaros-setup --profil statistik
```
