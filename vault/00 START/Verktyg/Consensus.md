# Consensus

> AI-sök i forskningsartiklar i molnet

**Fas:** 1 · Utforska  
**Profil:** AI-tjänster i molnet (tillval)

## Vad det används till

AI-sök i forskningsartiklar. Molntjänst. Det du skriver skickas till tjänsten.

## Installera

Öppna appen *DegsellOS*, välj **Välj forskningsverktyg** och installera **AI-tjänster i molnet (tillval)**, eller kör:

```bash
degsellos-setup --profil moln
```
