# Zotero

> Källhantering och citat

**Fas:** 1 · Utforska  
**Profil:** Grund  
**Topp 10 för forskare**

## Hur det tjänar metoden

Utforska: samla källor med metadata så att varje påstående kan spåras till sitt belägg (tillit).

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Grund**, eller kör:

```bash
forskaros-setup --profil grund
```
