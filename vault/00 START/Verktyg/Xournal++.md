# Xournal++

> Anteckna direkt i PDF:er

**Fas:** 1 · Utforska  
**Profil:** Grund  
**Ingår i det rekommenderade urvalet**

## Vad det används till

Anteckningar och markeringar direkt i PDF:er.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Grund**, eller kör:

```bash
forskaros-setup --profil grund
```
