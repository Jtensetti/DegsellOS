# jamovi

> Statistik med klick, byggt på R

**Fas:** 5 · Utveckla  
**Profil:** Statistik och data

## Hur det tjänar metoden

Utveckla: analyser du kan klicka fram och sedan se som R-kod, en bro från klick till kod.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Statistik och data**, eller kör:

```bash
forskaros-setup --profil statistik
```
