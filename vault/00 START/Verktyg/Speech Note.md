# Speech Note

> Transkribering helt på din dator

**Fas:** 5 · Utveckla  
**Profil:** Kvalitativ forskning  
**Topp 10 för forskare**

## Hur det tjänar metoden

Utveckla: transkribera intervjuer utan att ljudet lämnar datorn, vilket ofta krävs vid etikprövning.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Kvalitativ forskning**, eller kör:

```bash
forskaros-setup --profil kvalitativ
```
