# Speech Note

> Transkribering helt på din dator

**Fas:** 5 · Utveckla  
**Profil:** Kvalitativ forskning  
**Ingår i det rekommenderade urvalet**

## Vad det används till

Transkribering och diktering lokalt, utan att ljudet lämnar datorn.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Kvalitativ forskning**, eller kör:

```bash
forskaros-setup --profil kvalitativ
```
