# git-annex

> Versionshantera stora datafiler

**Fas:** 6 · Ompröva  
**Profil:** Programmering och reproducerbarhet

## Hur det tjänar metoden

Ompröva: se exakt vilken version av data en slutsats byggde på.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Programmering och reproducerbarhet**, eller kör:

```bash
forskaros-setup --profil programmering
```
