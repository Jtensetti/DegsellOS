# Typst

> Modern sättning, enklare än LaTeX

**Fas:** 7 · Dela  
**Profil:** Skriva och publicera

## Vad det används till

Sättningssystem för PDF, enklare än LaTeX.

## Installera

Öppna appen *DegsellOS*, välj **Välj forskningsverktyg** och installera **Skriva och publicera**, eller kör:

```bash
degsellos-setup --profil skriva
```
