# Taguette

> Kodning av intervjuer och dokument

**Fas:** 5 · Utveckla  
**Profil:** Kvalitativ forskning

## Hur det tjänar metoden

Utveckla: koda kvalitativa data och se mönster över intervjuer.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Kvalitativ forskning**, eller kör:

```bash
forskaros-setup --profil kvalitativ
```
