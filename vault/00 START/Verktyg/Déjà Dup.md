# Déjà Dup

> Säkerhetskopiering

**Fas:** 6 · Ompröva  
**Profil:** Grund

## Hur det tjänar metoden

Ompröva: din vault är din forskningshistoria. Säkerhetskopiera den.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Grund**, eller kör:

```bash
forskaros-setup --profil grund
```
