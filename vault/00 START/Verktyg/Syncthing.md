# Syncthing

> Dela projektmappar direkt mellan datorer

**Fas:** 5 · Utveckla  
**Profil:** Möten och samarbete

## Vad det används till

Dela ett forskningsprojekt med medarbetare utan molntjänst. Skyddat material ska inte delas på det här sättet utan stöd i projektets tillstånd.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Möten och samarbete**, eller kör:

```bash
forskaros-setup --profil samarbete
```
