# Alpaca

> Chatt med lokala modeller

**Fas:** 4 · Pröva  
**Profil:** Lokal AI  
**Ingår i det rekommenderade urvalet**

## Vad det används till

Chattgränssnitt för lokala modeller via Ollama.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Lokal AI**, eller kör:

```bash
forskaros-setup --profil lokal-ai
```
