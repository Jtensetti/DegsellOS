# DuckDB

> Snabb SQL direkt på CSV- och Parquet-filer

**Fas:** 5 · Utveckla  
**Profil:** Statistik och data

## Hur det tjänar metoden

Utveckla: utforska stora öppna datamängder (SCB, Eurostat) utan databasserver.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Statistik och data**, eller kör:

```bash
forskaros-setup --profil statistik
```
