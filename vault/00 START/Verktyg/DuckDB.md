# DuckDB

> Snabb SQL direkt på CSV- och Parquet-filer

**Fas:** 5 · Utveckla  
**Profil:** Statistik och data

## Vad det används till

SQL direkt på CSV- och Parquet-filer, utan databasserver.

## Installera

Öppna appen *DegsellOS*, välj **Välj forskningsverktyg** och installera **Statistik och data**, eller kör:

```bash
degsellos-setup --profil statistik
```
