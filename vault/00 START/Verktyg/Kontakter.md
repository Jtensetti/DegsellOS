# Kontakter

> Personerna i ditt nätverk

**Fas:** 4 · Pröva  
**Profil:** Grund

## Vad det används till

Spara de personer du möter, med kompetens och fält. Forskningsmötena i forskningsmappen pekar på samma personer.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Grund**, eller kör:

```bash
forskaros-setup --profil grund
```
