# Firefox

> Webbläsare

**Fas:** 1 · Utforska  
**Profil:** Grund  
**Topp 10 för forskare**

## Hur det tjänar metoden

Ingången till forskningsportalen: OpenAlex, DiVA, SwePub och de öppna databaserna.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Grund**, eller kör:

```bash
forskaros-setup --profil grund
```
