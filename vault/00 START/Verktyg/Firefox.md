# Firefox

> Webbläsare

**Fas:** 1 · Utforska  
**Profil:** Grund  
**Ingår i det rekommenderade urvalet**

## Vad det används till

Webbläsare för litteratursök och öppna databaser (se Verktygslåda).

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Grund**, eller kör:

```bash
forskaros-setup --profil grund
```
