# Zettlr

> Akademiskt skrivande i Markdown

**Fas:** 7 · Dela  
**Profil:** Skriva och publicera  
**Ingår i det rekommenderade urvalet**

## Vad det används till

Markdown-redigerare för längre texter, med citat från Zotero.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Skriva och publicera**, eller kör:

```bash
forskaros-setup --profil skriva
```
