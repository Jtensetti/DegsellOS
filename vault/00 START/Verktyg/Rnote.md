# Rnote

> Handskrivna skisser

**Fas:** 2 · Kombinera  
**Profil:** Idéer och modeller

## Vad det används till

Handskrivna anteckningar och skisser.

## Installera

Öppna appen *DegsellOS*, välj **Välj forskningsverktyg** och installera **Idéer och modeller**, eller kör:

```bash
degsellos-setup --profil ideer
```
