# draw.io

> Diagram, modeller och flöden

**Fas:** 2 · Kombinera  
**Profil:** Idéer och modeller  
**Topp 10 för forskare**

## Hur det tjänar metoden

Kombinera: rita din teoretiska modell. Det som inte går att rita är ofta inte genomtänkt.

## Installera

Öppna *ForskarOS – verktygslåda* och välj **Idéer och modeller**, eller kör:

```bash
forskaros-setup --profil ideer
```
