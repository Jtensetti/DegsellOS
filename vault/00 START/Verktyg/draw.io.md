# draw.io

> Diagram, modeller och flöden

**Fas:** 2 · Kombinera  
**Profil:** Idéer och modeller  
**Ingår i det rekommenderade urvalet**

## Vad det används till

Diagram, flödesscheman och modeller.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Idéer och modeller**, eller kör:

```bash
forskaros-setup --profil ideer
```
