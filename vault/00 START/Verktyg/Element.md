# Element

> Chatt för forskargrupper (Matrix)

**Fas:** 5 · Utveckla  
**Profil:** Möten och samarbete

## Vad det används till

Ett gemensamt rum per projekt för dem som arbetar med underlaget.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Möten och samarbete**, eller kör:

```bash
forskaros-setup --profil samarbete
```
