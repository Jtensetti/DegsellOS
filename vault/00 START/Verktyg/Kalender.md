# Kalender

> Boka forskningsmöten

**Fas:** 4 · Pröva  
**Profil:** Grund

## Vad det används till

Boka mötet där någon utanför projektet får invända, och följ upp det du lovade.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Grund**, eller kör:

```bash
forskaros-setup --profil grund
```
