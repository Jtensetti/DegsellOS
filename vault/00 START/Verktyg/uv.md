# uv

> Python-miljöer per projekt

**Fas:** 5 · Utveckla  
**Profil:** Programmering och reproducerbarhet

## Vad det används till

Hanterar Python-versioner och paket per projekt.

## Installera

Öppna appen *ForskarOS*, välj **Välj forskningsverktyg** och installera **Programmering och reproducerbarhet**, eller kör:

```bash
forskaros-setup --profil programmering
```
