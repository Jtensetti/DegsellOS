# ripgrep

> Sök snabbt i anteckningar och data

**Fas:** 2 · Kombinera  
**Profil:** Programmering och reproducerbarhet

## Vad det används till

Snabb textsökning i filer och mappar.

## Installera

Öppna appen *DegsellOS*, välj **Välj forskningsverktyg** och installera **Programmering och reproducerbarhet**, eller kör:

```bash
degsellos-setup --profil programmering
```
