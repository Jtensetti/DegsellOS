# ForskarOS

I sidopanelen för ForskarOS Core (hjärnikonen) hittar du dina forskningsfrågor, vilken fas varje fråga befinner sig i och vad som behöver följas upp.

Skrivbordsappens projekt med data, analys och manus ligger normalt i `~/Forskningsprojekt`. Den här forskningsmappen, `~/ForskarOS`, innehåller Core-anteckningarna. Ett projekt som är kopplat till en forskningsfråga skriver sitt läge till `04 EXPERIMENT`.

## Kom igång

1. Läs [[00 START/Arbetsmetod|Arbetsmetod]], [[00 START/Begreppen|Begreppen]] eller [[00 START/Forskarhandboken/00 Innehåll|Forskarhandboken]].
2. Skapa en forskningsfråga i panelen, eller använd förslaget i `01 RIKTNING`.
3. Arbeta i faser: Utforska, Kombinera, Välj, Pröva, Utveckla, Ompröva, Dela.
4. Gör en förmågegranskning en gång i månaden.

## Mappar

| Mapp | Innehåll |
|---|---|
| 01 RIKTNING | Forskningsfrågor och idébank |
| 02 HYPOTESER | Hypoteser |
| 03 EVIDENS | Perspektivkartor och källor |
| 04 EXPERIMENT | Experiment, arbetsprov och projekt från appen |
| 05 FRIKTION | Motprov |
| 06 FÖRÄNDRING | Omprövningar |
| 07 SAMVERKAN | Forskningsmöten och samarbeten |
| 08 REFLEKTION | Forskarpass, AI-loggar, övningar, förmågegranskningar |
| 09 ARKIV | Avslutade anteckningar |

## Säkerhetskopior

Säkerhetskopiera både `~/ForskarOS` och `~/Forskningsprojekt`, exempelvis med Déjà Dup. Git kan användas för versionshantering av anteckningar och kod.

Lägg inte personuppgifter eller sekretessbelagt material i molntjänster.
